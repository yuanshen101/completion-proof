# Demo storyboard: actual replay and optional live plan

**The follow-up kit includes a real replay MP4**, not a live screen recording:
`evidence/demo/completion-proof-demo.mp4` (23 s, H.264, 1280×720), generated by
`scripts/record_demo.py` from actual commands executed against the current
plugin in an isolated `HERMES_HOME`. It is explicitly labelled **replay, not
live**; actual execution time is recorded separately. This storyboard remains
the plan for a future live recording with narration if desired.

## Target: under 90 seconds

| Time | Visual | Spoken line |
|---|---|---|
| 0–8 s | `hermes plugins list` shows `completion-proof enabled` | “This is a native Hermes plugin, installed from a deterministic archive.” |
| 8–20 s | Show the check config: `id: unit`, argv, source/test globs, timeout | “The check is operator configuration. The model cannot pass a command or a cwd to it.” |
| 20–38 s | `hermes completion-proof verify` → `FAIL`, exit 1, stdout says “tests passed” | “The command printed ‘passed’ but exited 1. The receipt is FAIL; the text is not evidence.” |
| 38–55 s | Fix `src/app.py`, rerun verify → `PASS`, scope summary and hashes | “Now it exits 0. The receipt records the command, exit code, duration, output hashes and every scoped file hash.” |
| 55–70 s | `hermes completion-proof status` → `PASS`, fresh | “Fresh means the current fingerprint matches the receipt, not that the software is perfect.” |
| 70–82 s | Edit a covered source file, run status → `STALE` | “One relevant change and the old PASS is STALE. Historical evidence is kept, but it is not current proof.” |
| 82–90 s | Show `/proof` or `proof_verify` tool and the limitations line | “Completion Proof: a receipt tied to this revision, not a memory of a command.” |

## Recording script

1. Prepare a throwaway Hermes home with `installs/` (do not use a real profile):

   ```bash
   export CP_HERMES_TEMPLATE_HOME="${TMPDIR:?}/cp-hermes-template"
   ```

2. Record the terminal while running the pre-written demo, which creates its own
   isolated `HERMES_HOME`, project, ledger and config:

   ```bash
   bash scripts/demo.sh
   ```

3. If a real recording tool is available, capture the same commands with
   `asciinema rec` or OBS; keep the resulting file under 90 seconds. Do not edit
   the command outputs.
4. Show `evidence/hooks/mock_requests.jsonl` only as supporting material if the
   native hook is discussed. It is a local mock-provider test, not a paid model
   run; say so.

## Narration constraints

- Do not claim cryptographic tamper-proofing.
- Do not say “all tests pass”; say “the configured command exited 0 on the
  declared scope”.
- Do not claim Windows validation.
- Do not call this “ready to submit”: public repo, catalog pin, video, X post,
  form and the operator eligibility decision are unresolved.
